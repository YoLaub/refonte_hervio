# Photos des praticiennes

Déposer ici les portraits des sages-femmes, puis décommenter la ligne `photo:`
correspondante dans `src/data/site.ts` :

- `lenaig.jpg` → Lénaïg Hervio - Le Mercier (`photo: '/equipe/lenaig.jpg'`)
- `julie.jpg`  → Julie Quintin (`photo: '/equipe/julie.jpg'`)

Recommandations :
- Format carré, au moins **512×512 px** (affiché en cercle de 128 px, ×2 pour les écrans Retina).
- JPG ou WebP optimisé (< 150 Ko idéalement).
- Cadrage portrait, visage centré.
- Vérifier les droits d'utilisation (cf. crédit « RLG Photographie » du site actuel).

Tant qu'aucune photo n'est fournie, un avatar avec les initiales s'affiche automatiquement.
