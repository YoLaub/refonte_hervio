# Photos d'illustration des prestations

Déposer ici les photos illustrant chaque prestation, puis renseigner le champ `image:`
dans le frontmatter de la fiche correspondante (`src/content/services/<slug>.md`) :

```yaml
image: /services/reeducation-du-perinee.jpg
```

Recommandations :
- Paysage, ratio ~16/9, au moins **800×450 px**, JPG/WebP optimisé (< 200 Ko).
- Ambiance douce et rassurante, cohérente avec la charte (verts sauge, lumière naturelle).
- Vérifier les droits d'utilisation des images.

Sans `image:`, une illustration placeholder (dégradé + icône thématique par catégorie)
s'affiche automatiquement — le site reste illustré en attendant les vraies photos.
